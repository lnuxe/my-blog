我在做什么

用一句话概括我的自我定位，就是仓库里写着的那句：

全栈开发，重度浏览器自动化爱好者。白天写业务，晚上写机器人替自己干活。相信「能自动化的绝不手动」。

这句话落到具体的事情上，大概分成三个方向：

  • 浏览器自动化。用 Playwright 把重复的点击、校验、上架流程交给机器；原则是「能被代码表达的规则不交给模型」，模型只在规则层失败时兜底。
  • AI Agent 技能包。给 Cursor / Claude Code 写可以直接落地的 skill：怎么导出数据、怎么组织知识库、怎么在改代码之前先对齐问题。
  • Flutter 多端。用一套 Dart 代码覆盖桌面与移动端，做一些自己会用的工具。

除了上面这些，还有一些在持续沉淀但还没单独开仓库的东西：Mini-apps 活动组件库（电商营销活动页的组件化开发，比如 VIP 卡池、海外生活频道这类 H5 活动）和 auto_test 回归框架（页面回归 + 流程编排，产出健康报告）。

这个站点

本站是一个完全静态的站点：纯 HTML、一份 CSS、一份原生 JavaScript，没有任何构建步骤，也没有 CDN、没有 Web Font、没有外部图片，图标全是内联 SVG。它既能直接双击离线阅读，也能丢进任意静态服务器运行。

首页的 3D 背景与卡片景深用了两个开源库——three.js 与 Atropos，都是 MIT 许可，文件本地自带在仓库里，所以站点依旧没有任何外部网络请求。除此之外没有别的依赖。

这么做的理由很实际：以前大部分时间花在维护工具链上，而不是写东西上。把依赖削减到零之后，写一篇新文章的启动成本只剩下「复制一个文件，改几行字」。文章里的代码片段、目录结构、参数名都来自各仓库的真实内容，没有经过润色加工。
