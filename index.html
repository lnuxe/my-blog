  • starmerx_listing

    Python

    基于 Playwright 的确定性浏览器自动化，跑通「产品池 → 加入上架计划 → 图片/价格校验 → 批量上架」全流程。

    • Python 3.13 + Playwright 1.62 做确定性 DOM 操作，通义千问 Qwen 仅在规则层失败时兜底
    • 钉钉扫码登录 + storageState 持久化，登录态约 2 天过期
    • 利润试算引擎用有界二分，最多 20 次迭代，未命中即报「需人工介入」
    • 默认干运行，加 --no-dry-run 才真正上架
    GitHub

  • rag-cs-bot

    TypeScript

    基于 Dify RAG 的电商客服自动化 Demo：售前 AI 自动回复，售后从机制上强制转人工。

    • 本地 Dify + RAG 知识库，Flask 前端代理转发 API 并剥离 DeepSeek 思考过程
    • UI-TARS 浏览器自动化读取买家消息，调 Dify 生成回答后回填
    • 知识库只放售前内容，售后不喂给 AI
    • 面向每天 99+ 条消息、受 TikTok 24h / 48h 考核约束的店铺场景
    GitHub

  • pickled-fish

    HTML

    泡菜鱼：跑在 Cursor Agent 上的技能包 —— 微信本机聊天导出、整段聊天分析、文件系统 RAG。

    • 面向 WeChat 4.1.10+，LLDB 抓 passphrase → PBKDF2 解密 db_storage/*.db
    • wxecho export "昵称" 写出 ~/Downloads/wxecho/<联系人>/chat.txt
    • Index-first 文件系统 RAG：REGISTRY → PACK.md → rg → Read
    • 同轮最多深读 2 个 pack 并强制标注 packs_used
    GitHub

  • flutter-defect-triage

    Shell

    Cursor / Claude Code 用的缺陷分诊 skill，面向 Flutter Web、App WebView、小程序 H5、多宿主 JSBridge 等高坑密度场景。

    • 核心理念：先对齐坑，再写修复

    • 合入后必须回填 cases.md 与 cases-rag-index.md

  • preaim-rush-peek

    JavaScript

    无畏契约风格的瞄准训练器，专注「击杀 → 转火 → 再击杀」的 rush 抗压与快速补枪训练。

    • Vite 5 + PixiJS 8 + Three.js，无后端、无框架、无运行时依赖
    • 2D / 3D 双模式（?mode=3d），三维模式走射线命中判定

    • 分轨音效，MP3 缺省自动回退合成音效

  • ldm / wechat-mcp

    JavaScript

    macOS 上通过 MCP 操作微信桌面版的示例服务器：发送消息、读取当前聊天窗口可见文本。

    • get-current-chat-text：读取当前聊天窗口里可见的文本内容
